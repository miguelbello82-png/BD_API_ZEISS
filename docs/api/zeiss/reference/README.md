# ZEISS API Reference

O JSON sanitizado que porventura constar neste diretório (`API-ZEISS.sanitized.json`) serve **apenas como referência documental**, não como fonte de credenciais ou para execução de chamadas ativas na aplicação.

Qualquer export original deve passar pelo processo de sanitização, convertendo segredos para `{{ZEISS_API_KEY}}` e dados reais sensíveis ou PII para dados sintéticos.
